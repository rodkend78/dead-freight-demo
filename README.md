# Dead Freight — browser demo

[Play Dead Freight](https://rodkend78.github.io/dead-freight-demo/)

Version 0.20.0. A solo extraction shooter with three connected industrial districts, climbable cover and roofs, optional objectives, utilities, and an equipment blueprint hidden in the Flooded Rail Depot.

Desktop keyboard and mouse. Click **Load Dead Freight**, then **Enter the yard**. Select a weapon and press **Enter** to deploy. **WASD** moves, **Space** jumps, mouse aims/fires, **R** reloads, **E** interacts, **Q** heals, and **G** throws your fitted utility. Hold **E** at extraction for five seconds to bank your haul. **Escape** pauses, **M** opens the map, and **F3** opens the workbench in preparation.

Progress stays in the browser profile and website origin where you play. Use **Save backup** before clearing site storage. Desktop and browser progress are separate; cross-device sync and backup import are not implemented.

This repository contains only the compiled Unity Web export and its payload checksums. The editable project is maintained separately. No player saves, QA profiles or private project source are included.

Chrome, Firefox and WebKit test-engine checks are described in the game's release validation. Shipping Safari, mobile controls, controller input and broad hardware acceptance remain unverified. Automated pilot results do not establish human difficulty or engagement.
